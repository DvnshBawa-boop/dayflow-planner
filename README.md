# DayFlow Planner

A mobile-friendly to-do list, daily planner and habit tracker that runs in the browser.

**Live demo:** https://dayflow-planner-iota.vercel.app

<img width="1365" height="633" alt="image" src="https://github.com/user-attachments/assets/c0bbd854-303d-4293-8833-b1375c696e9a" />


## Features
- Task management with priorities, categories and filters
- Daily time-blocking schedule
- Habit tracker with daily check-ins and streaks
- Categories and tags
- Settings: focus timer, data backup/export, light/dark theme
- Data is saved locally in your browser (no account needed)

## Tech stack
React, TypeScript, Vite, Tailwind CSS

## Run locally
```bash
git clone https://github.com/DvnshBawa-boop/dayflow-planner.git
cd dayflow-planner
pnpm install
pnpm dev
```

## How it was built
Built as a learning project using Dyad (an open-source AI app builder) with Google Gemini and OpenRouter models. I reviewed and tested the output and fixed issues along the way, including import errors and storage bugs.
